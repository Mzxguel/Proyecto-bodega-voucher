# Proyecto Bodega Voucher

Estado: En desarrollo

## Resumen

Proyecto Bodega Voucher es una aplicación diseñada para gestionar vouchers y movimientos de inventario en una bodega/almacén. Proporciona funcionalidades para crear, validar y contabilizar vouchers (comprobantes) vinculados a entradas y salidas de stock.

---

## Características

- Gestión de vouchers (crear, validar, listar).
- Control de entradas y salidas de inventario vinculadas a vouchers.
- Registro de movimientos por artículo, lote y ubicación.
- Búsqueda y filtrado avanzado (por fecha, artículo).
- Los vouchers se generan en pdf ademas de poder añadirle la imagen de la empresa.
- Role solo para el administrador o cajero.
